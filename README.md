# Network Security Mini Project

This project demonstrates practical implementation of core network security concepts including PKI, HTTPS configuration, firewall rules, and TLS handshake analysis.

## Objectives
- Implement Public Key Infrastructure (PKI)
- Generate SSL certificates using OpenSSL
- Configure HTTPS using Apache server
- Build a firewall using iptables
- Analyze TLS handshake using Wireshark

## Tools & Technologies
- Linux (SEED VM)
- OpenSSL
- Apache Web Server
- Wireshark
- iptables

## Project Tasks

### 1. PKI Implementation
- Create Certificate Authority (CA)
- Generate server private key
- Create CSR
- Sign certificate using CA

### 2. Firewall Configuration
- Default DROP policy
- Allow HTTP/HTTPS traffic
- Block malicious IP
- Enable DNS traffic

### 3. TLS Analysis
- Capture handshake using Wireshark
- Analyze Client Hello & Server Hello
- Inspect certificate exchange
- Understand encryption process

## Outcome
This project provides hands-on experience in securing communication using encryption and network protection techniques.
